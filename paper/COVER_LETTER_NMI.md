Dear Editors of Nature Machine Intelligence,

Please consider our Article, **“Causal cognitive-map interfaces for language models: when brain-inspired spatial codes help, and when they do not,”** for publication in *Nature Machine Intelligence*.

Large language models can describe spatial relationships without necessarily maintaining a metric state that survives self-motion. This work asks whether an explicitly structured cognitive-map interface can supply that missing state, and—equally importantly—when such brain-inspired structure is actually useful rather than merely decorative.

The manuscript makes four linked contributions. First, causal cortex-ON/OFF and organ-specific lesion experiments show that a frozen language model can use a latent cognitive-map channel to answer spatial questions when the trajectory itself is absent from the prompt. Second, matched non-neural controls establish a sharp boundary condition: ordinary Euclidean path integration is not uniquely solved by grid-like coding, because a permutation-invariant additive Transformer statistically ties it. The structured population code becomes advantageous only when its specific properties—periodicity, remapping or bounded population structure—are computationally load-bearing. Third, the strongest prospective effect, theta-sweep look-ahead, replicates across two open-weight language-model families, Qwen2.5-1.5B and SmolLM2-1.7B. Fourth, the fixed representation transfers without architectural changes to user-disjoint real human trajectories from Microsoft GeoLife, where it supports accurate bearing and distance decoding from unseen users.

We believe this combination of causal intervention, negative controls, cross-backbone replication and external real-world validation is particularly appropriate for *Nature Machine Intelligence*. The paper does not argue that biologically inspired architectures are universally superior. Instead, it provides a falsifiable regime map for when a neural-style cognitive-map representation changes machine reasoning and when simpler inductive biases suffice.
